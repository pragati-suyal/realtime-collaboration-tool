# CollabCode - Real-Time Collaboration Tool

A complete real-time multi-user coding and note-taking application.

## Technologies

- Node.js
- Express.js
- Socket.IO
- HTML5
- CSS3
- JavaScript

## Features

1. Create collaboration room
2. Join existing room
3. Real-time shared editor
4. Multiple users
5. Online user list
6. Typing indicator
7. Team chat
8. Language selection
9. Clear shared document
10. Download code
11. Shareable room link
12. Responsive UI

## Installation

Install Node.js first.

Then run:

npm install

Start server:

npm start

Open:

http://localhost:3000

## Testing

Open the application in one browser.

Enter your name.

Click:

Create Room

Copy the room ID or invite link.

Open another browser/window.

Enter another user's name.

Join the same room.

Now type in the editor.

The document changes will be visible to all connected users.
